**r2rtnl** (2026-03-22T12:30:00.000Z) [msgid:$hG0PGv_LEnXyYWFTOBnV8V3Klw9Bx-alKnJUH2irDI0]:
The four preimage-related host calls (solicit, forget, query, provide) accept the preimage length z as a 64-bit register value, but the preimage lookup dictionary defines its key as (hash, bloblength = N_{2^{32}}). This inconsistency causes the storage footprint to exceed its declared type for large z. Multiplying it with B_L to compute the balance threshold could compounds the problem if the constant is increased. Adding an explicit z ∉ bloblength → HUH guard to all four calls is proposed.
