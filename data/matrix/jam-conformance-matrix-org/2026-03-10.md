**wei** (2026-03-10T05:49:00.000Z) [msgid:$YRI0AG0MI48ud2wM5DrOrRdLKbd3SPYutA_iU3mZr-g]:
Hey everyone! Following yesterday's announcement of the Grey implementation, I also want to announce another project **JAR -- JAM Axiomatic Reference**.

This is (or will be) a complete specification of JAM re-written using the Lean 4 proof assistant. The goals for us are several:

- We want to address some of the ambiguity we found in Gray Paper, and I think this is best done by an actual specification written in a proof assistant.
- We now have the Grey implementation, which (more or less) passes the conformance tests. Grey and JAR can act at each other's reference, and we can gradually ensure the correctness of the JAR specification.
- We want to write some proofs and not accidentally break them when making changes. Lean 4 is probably the best tool for this.
- And finally, we also want to have something more readable than Gray Paper. It hurts my eyes! 😅

This is still a new work, but you can see its current status here: https://bitarray.github.io/jar
We also have a new discussion room if you want to discuss something really specific to JAR: #jar:matrix.org
