**jan** (2026-06-05T09:15:00.000Z) [msgid:$2c682RwShBnouzcON325DwSPf_ksib6PZCNGRwVQYao]:
Note that M4 will most likely have the following requirements:
- Each toplevel VM and associated inner VMs will have to run pinned to a single core where nothing else is allowed to run (sans some allowance for a small runtime for you to manage the VM).
- You'll need to be able to spawn new inner VMs without leaving the core.
- You'll need to be able to switch between the toplevel VM and the inner VM without leaving the core.
- You'll have to process page faults (for both the outer VM and the inner VM; currently only inner VMs need this, but with page gas metering outer VMs will need it too) without leaving the core.

**jan** (2026-06-05T09:17:00.000Z) [msgid:$uOxOcmOY5hQEJRT5OL7zi9l_pOolICpDdKn2ufU_dXw]:
