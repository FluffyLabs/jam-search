**davxy** (2025-06-28T15:01:00.000Z) [msgid:$cvekGRxFnnpDMj00lMb8XxdP88k-sdQES_piizR3SHU]:
Basically when you start the fuzzer against a target you can specify a --source arg.
Currently it can be:

- local: polkajam engine (no I've not rewritten the whole onchain logic for the fuzzer ;-) )
- remote: some other impl
- trace: traces in the filesystem. Same format as the ones in jam-test-vectors.

Only the local source is fuzzed using the logic I wrote. Nothing prevents someone to implement their source to be used as remote source by the tool. The source must follow the protocol I shared (the fuzzer side in this case)
