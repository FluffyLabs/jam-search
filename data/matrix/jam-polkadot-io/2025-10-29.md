Hello everyone, I've released a telemetry server which is compatible with JIP-3 for JAM nodes. You can find the release binaries here

This consists of two parts, the backend (telemetry server) which stores emitted events from connected nodes in postgres. The recommended way to run this is in docker, but you can find a variety of helper scripts in the repo to modify to your environment as needed.

The other part is the cli interface, which is TUI, called tart-dash.

If anyone has any problems, suggestions, or otherwise, please ping me!
