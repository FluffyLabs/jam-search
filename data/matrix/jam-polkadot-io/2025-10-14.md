We recently changed RPC API to use BASE64 encoding for all binary data, including hashes, preimages, segments and other similar types. According to our benchmarks it is much faster to encode a byte array to a BASE64 string and send than to encode it as JSON and send, even for small arrays. This statement is true for both Rust and Javascript-based clients.

You can find the relevant JIP PR here: https://github.com/polkadot-fellows/JIPs/pull/9
