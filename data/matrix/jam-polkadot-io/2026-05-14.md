**tomusdrw** (2026-05-14T09:15:00.000Z) [msgid:$TYHeQYOWeJYp2wyly0rULNRkk3dawoFVvcyBMnL4DOs]:
FYI: The last couple of months I've been working on WASM -> PVM (re)compiler:
https://github.com/tomusdrw/wasm-pvm

It's was heavily AI-assisted, but surprisingly I think it works quite well. Recently I was able to recompile all existing polkadot runtimes to PVM (no running though, since I don't have any environment for that (host call handlers, data, etc)).

Obviously polkadot runtime are better compiled directly to PVM from Rust, but being able to translate arbitrary WASM programs to PVM has some benefits as well, for instance being able to compile wider range of programming languages and use WASM as an IR.

An application for this kind of re-compiler I always had in mind is AssemblyScript JAM SDK: github.com/tomusdrw/as-lan

Surprisingly enough, some examples are smaller in size than Rust JAM-SDK even though they go through AS -> WASM -> PVM path.

You can try it out to write services for JAM. IMHO it's pretty cool to have a JavaScript-like language, with a really simple learning curve as an entrypoint for JAM. You can easily try it out with our other tool "jammin": https://github.com/jammin-create/jammin-create-aslan
