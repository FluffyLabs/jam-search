**gav** (2024-06-24T11:17:00.000Z) [msgid:$mv2hqc1LQ0ctA9urq6jRy3R0bydp-1VfLQAo5AadYSc]:
Fellowship will be looking for evidence that the team coded the software themselves from the GP. That it’s not a port or AI adjusted version of some other team’s software. To this extent it’s important for the teams to demonstrate an organic development process. Regular, sensibly-sized commits are one way of doing this and we assume GitHub is reasonably corruption-resistant (git alone obviously isn’t). But if you don’t want to use GitHub then make sure you credibly timestamp the commits elsewhere such as on a public blockchain.
