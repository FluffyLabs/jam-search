<p><a href="https://redirect.github.com/biomejs/biome/pull/10094">#10094</a> <a href="https://github.com/biomejs/biome/commit/e00714360807115210e549caca0f235431ca9a8a"><code>e007143</code></a> Thanks <a href="https://github.com/THEjacob1000"><code>@​THEjacob1000</code></a>! - Added the nursery rule <a href="https://biomejs.dev/linter/rules/no-tailwind-arbitrary-value/"><code>noTailwindArbitraryValue</code></a>. <code>--stdin-file-path=subdirectory/...</code> would not use the nested configuration in
<code>subdirectory/biome.json</code>:</p>
<pre><code>├── biome.json
└── subdirectory
    ├── biome.json
    └── lib.js
</code></pre>

</code></pre>

that path is ignored and therefore not formatted or fixed.</p>
