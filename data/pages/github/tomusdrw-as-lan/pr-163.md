<h2>Biome CLI v2.5.14</h2>
<h2>2.5.14</h2>
<h3>Patch Changes</h3>
<ul>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/9022">#9022</a> <a href="https://github.com/biomejs/biome/commit/0d49e24f51af4568d9c64f0f18a5b2a2758b7fe3"><code>0d49e24</code></a> Thanks <a href="https://github.com/dyc3"><code>@​dyc3</code></a>! - Added the nursery rule <a href="https://biomejs.dev/linter/rules/no-return-in-finally/"><code>noReturnInFinally</code></a>. This rule disallows return statements in <code>Promise.prototype.finally()</code> callbacks, including inside nested blocks and conditional branches. Returns in nested functions are ignored by the rule.</p>
<pre lang="js"><code>// Invalid: return in finally callback
Promise.resolve(1).finally(() =&gt; { return 2 })
<p>// Valid: no return in finally callback<br />
Promise.resolve(1).finally(() =&gt; { console.log(2) })<br />
</code></pre></p>
<p>Returning a value from a <code>Promise.prototype.finally()</code> callback does not replace the original promise's fulfillment value, which can be confusing. Returned promises and thenables are awaited, and their rejection rejects the resulting promise.</p>
</li>
<li>
