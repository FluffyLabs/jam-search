<h2>Biome CLI v2.1.0</h2>
<h2>2.1.0</h2>
<h3>Minor Changes</h3>
<ul>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/6512">#6512</a> <a href="https://github.com/biomejs/biome/commit/0c0bf82c92ee4e853172f44e38af57afde6de2ce"><code>0c0bf82</code></a> Thanks <a href="https://github.com/arendjr"><code>@​arendjr</code></a>! - The rule <a href="https://biomejs.dev/linter/rules/no-misused-promises/"><code>noFloatingPromises</code></a> can now detect floating arrays of <code>Promise</code>s.</p>
<p><strong>Invalid examples</strong></p>
<pre lang="ts"><code>// This gets flagged because the Promises are not handled.
[1, 2, 3].map(async (x) =&gt; x + 1);
</code></pre>
<p><strong>Valid examples</strong></p>
<pre lang="ts"><code>await Promise.all([1, 2, 3].map(async (x) =&gt; x + 1));
</code></pre>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/6637">#6637</a> <a href="https://github.com/biomejs/biome/commit/6918085e14b8e34bfd0adc472acce22c31484ab3"><code>6918085</code></a> Thanks <a href="https://github.com/arendjr"><code>@​arendjr</code></a>! - Type inference is now able to handle the sequence operator (<code>,</code>), as well as post- and pre-update operators: <code>++</code>.</p>
<p><strong>Example</strong></p>
<pre lang="ts"><code>let x = 5;
<p>// We now infer that <code>x++</code> resolves to a number, while the expression as a whole
// becomes a Promise:
x++, new Promise((resolve) =&gt; resolve(&quot;comma&quot;));
</code></pre></p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/6752">#6752</a> <a href="https://github.com/biomejs/biome/commit/c9eaca4b944acfd18b700c65c904806b11c318d5"><code>c9eaca4</code></a> Thanks <a href="https://github.com/arendjr"><code>@​arendjr</code></a>! - Fixed <a href="https://redirect.github.com/biomejs/biome/issues/6646">#6646</a>: <code>.gitignore</code> files are now picked up even when running Biome from a nested directory, or when the ignore file itself is ignored through <code>files.includes</code>.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/6746">#6746</a> <a href="https://github.com/biomejs/biome/commit/90aeeadf80700aee9f29121511d0c4c9019a49d6"><code>90aeead</code></a> Thanks <a href="https://github.com/arendjr"><code>@​arendjr</code></a>! - <code>biome migrate</code> no longer enables style rules that were recommended in v1, because that would be undesirable for users upgrading from 2.0.</p>
<p>Users who are upgrading from Biome 1.x are therefore advised to first upgrade to Biome 2.0, and run the migration, before continuing to Biome 2.1 or later.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/6583">#6583</a> <a href="https://github.com/biomejs/biome/commit/d415a3f6f204cc7b109dc08f6117fe97ef07b216"><code>d415a3f</code></a> Thanks <a href="https://github.com/arendjr"><code>@​arendjr</code></a>! - Added the nursery rule <a href="https://biomejs.dev/linter/rules/no-misused-promises/"><code>noMisusedPromises</code></a>.</p>
<p>It signals <code>Promise</code>s in places where conditionals or iterables are expected.</p>
<p><strong>Invalid examples</strong></p>
<pre lang="ts"><code>const promise = Promise.resolve(&quot;value&quot;);
<p>// Using a <code>Promise</code> as conditional is always truthy:

</code></pre></p>
</li>
