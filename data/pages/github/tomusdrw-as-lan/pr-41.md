This rule helps prevent potential leaks when rendering components that use binary expressions or ternaries.</p>
<p>For example, the following code triggers the rule because the component would render <code>0</code>:</p>
<pre lang="jsx"><code>const Component = () =&gt; {
  const count = 0;

</code></pre>
</li>

Disallow JSX prop spreading the same identifier multiple times.</p>
<p><strong>Invalid:</strong></p>
