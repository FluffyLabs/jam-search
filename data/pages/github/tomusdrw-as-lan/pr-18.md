<p>This rule is intended for use in Qwik applications to warn about the use of <code>useVisibleTask$()</code> functions which require careful consideration before use.</p>
<p><strong>Invalid:</strong></p>
<pre lang="js"><code>useVisibleTask$(() =&gt; {
  console.log(&quot;Component is visible&quot;);
});
</code></pre>
<p><strong>Valid:</strong></p>
<pre lang="js"><code>useTask$(() =&gt; {
  console.log(&quot;Task executed&quot;);
});
</code></pre>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/7084">#7084</a> <a href="https://github.com/biomejs/biome/commit/50ca1553f08348ab1e92dc7cf04013c85ff743a4"><code>50ca155</code></a> Thanks <a href="https://github.com/ematipico"><code>@​ematipico</code></a>! - Added the new nursery rule <code>noUnnecessararyConditions</code>, which detects whenever some conditions don't
change during the life cycle of the program, and truthy or false, hence deemed redundant.</p>
<p>For example, the following snippets will trigger the rule:</p>
<pre lang="js"><code>// Always truthy literal conditions
if (true) {
  console.log(&quot;always runs&quot;);
}
</code></pre>
<pre lang="ts"><code>// Unnecessary condition on constrained string type
function foo(arg: &quot;bar&quot; | &quot;baz&quot;) {
  if (arg) {
    // This check is unnecessary
  }
</code></pre>
</li>
</ul>
