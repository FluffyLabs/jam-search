This rule detects Options API patterns in <code>&lt;script&gt;</code> blocks, <code>defineComponent()</code>, and <code>createApp()</code> calls,
helping prepare codebases for Vapor Mode adoption.</p>
<p>For example, the following now triggers this rule:</p>
<pre lang="vue"><code>&lt;script&gt;

  data() {
    return { count: 0 };
  },
};
&lt;/script&gt;
</code></pre>
