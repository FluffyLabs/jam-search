<blockquote>
<h2>Biome CLI v2.3.0</h2>
<h2>2.3.0</h2>
<h3>Minor Changes</h3>
<ul>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/7263">#7263</a> <a href="https://github.com/biomejs/biome/commit/a3e336937e4cef0aa4b9cd30fc4d3c195e967e86"><code>a3e3369</code></a> Thanks <a href="https://github.com/arendjr"><code>@​arendjr</code></a>! - Biome's resolver now supports <code>baseUrl</code> if specified in <code>tsconfig.json</code>.</p>
<h4>Example</h4>
<p>Given the following file structure:</p>
<p><strong><code>tsconfig.json</code></strong></p>
<pre lang="json"><code>{
  &quot;compilerOptions&quot;: {
    &quot;baseUrl&quot;: &quot;./src&quot;
  }
}
</code></pre>
<p><strong><code>src/foo.ts</code></strong></p>
<pre lang="ts"><code>export function foo() {}
</code></pre>
<p>In this scenario, <code>import { foo } from &quot;foo&quot;;</code> should work regardless of the
location of the file containing the <code>import</code> statement.</p>
<p>Fixes <a href="https://redirect.github.com/biomejs/biome/issues/6432">#6432</a>.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/7745">#7745</a> <a href="https://github.com/biomejs/biome/commit/6fcbc07e7379a34719485f306f2b4a7f7e4ed91a"><code>6fcbc07</code></a> Thanks <a href="https://github.com/dyc3"><code>@​dyc3</code></a>! - Added <code>ignore</code> option to <code>noUnknownAtRules</code>. If an unknown at-rule matches any of the items provided in <code>ignore</code>, a diagnostic won't be emitted.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/7753">#7753</a> <a href="https://github.com/biomejs/biome/commit/63cb7ff31dc7932cf06e5f2760ef657d411a7230"><code>63cb7ff</code></a> Thanks <a href="https://github.com/ematipico"><code>@​ematipico</code></a>! - Enhanced the <code>init</code> command. The <code>init</code> command now checks if the existing project contains known ignore files and known generated folders.</p>
<p>If Biome finds <code>.gitignore</code> or <code>.ignore</code> files, it will add the following configuration to <code>biome.json</code>:</p>
<pre lang="diff"><code>{
+  &quot;vcs&quot;: {
+    &quot;enabled&quot;: true,
+    &quot;clientKind&quot;: &quot;git&quot;,
+    &quot;useIgnoreFile&quot;: true
+  }
}
</code></pre>
<p>If Biome finds a <code>dist/</code> folder, it will exclude it automatically using the double-exclude syntax:</p>
</li>
