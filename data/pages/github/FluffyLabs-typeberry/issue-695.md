# Block export

## Issue by @tomusdrw

It should be possible to export blocks from the database.

Currently we can only import `bin` or `JSON` blocks. We should also be able to export `bin` blocks, either one block per file or in a more concatenated form.

Whatever is exported from a node it should also be possible to import on another node.
