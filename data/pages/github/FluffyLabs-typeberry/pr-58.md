# PVM: load ind instructions

## Pull Request by @mateuszsikora

# What?
This PR introduces support for load instructions that use indirect addressing. The logic here is similar to other load instructions, the difference is only in memory address. It works exactly the same like in case of store ind instructions. One part of an address is immediate number and the second part is stored in a register. Those two numbers have to be summed to get the address.
