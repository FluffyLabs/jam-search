# Introduce IPC extension & IPC2RPC server

## Pull Request by @tomusdrw

This PR adds an test IPC extension which exposes an IPC socket that can be used to communicate with the running node.

IPC socket speaks a subset of JAM-SNP. QUIC streams are simulated by sending enveloped data (which indicates which stream the data is coming from). The PR also introduces the UP0 stream definition from JAM-SNP to support block announcements.

`tools/ipc2rpc` is a client connecting to that IPC and initiating UP0 stream to listen to block announcements. Every time the node imports a block, the client is notified and updates it's internal DB. That DB is later exposed as JSON-RPC over HTTP server. The `index.html` page is displaying the current best header as JSON by requesting polling that info from the JSON-RPC.

The code is pretty dirty, but again it's mostly for the demo, so I hope it will be reworked.

Should only be merged after #141, but can be reviewed already.
