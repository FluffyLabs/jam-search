# PVM: dynamic jumps

## Pull Request by @mateuszsikora

# What?
1. Fixed `JumpTable` implementation. At the beginning I thought that the purpose of this table is possibility to check validness of dynamic jump destination. It was incorrect. `JumpTable` is kind of map that we need to transform an index into a new program counter.
2. Added implementation of `djump` function from GP that correctly handles all cases.
