# PVM: rename getArgs to fillArgs and pass result array as param

## Pull Request by @mateuszsikora

# What?

- renamed `ArgsDecoder.getArgs(pc: number)` to ArgsDecoder.fillArgs<T extends Args>(pc: number, result: T)`
- renamed args decoding result types - the suffix was changed from `-Result` to `-Args`
- renamed `firstRegisterIndex` to `registerIndex` when there is only one register

This PR resolves https://github.com/FluffyLabs/typeberry/issues/35
