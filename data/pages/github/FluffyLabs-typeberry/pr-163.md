# Read + Write + Info host calls

## Pull Request by @tomusdrw

Implementation of `read`, `write` and `info` general host calls.

- `read` is responsible for reading stuff from state into memory
- `write` is (over)writing data in the state
- `info` is returning jam-encoded service account details (like code hash, storage utilisation, balance, etc).
