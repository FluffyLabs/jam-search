## Comment by @tomusdrw

Just realised, we can have multiple requests in parallel, so we shouldn't be overwriting the old callback.

```suggestion
    const oldOnResponse = this.onResponse.get(sender.streamId);
    this.onResponse.set(sender.streamId, (state) => {
       oldOnResponse?.(state);
       onResponse(state);
    });
```

Or we should store a list there.


## Comment by @skoszuta

We create one stream per RPC request. Is it really possible to have multiple requests within one stream then?


## Comment by @tomusdrw

Ah, that's true. I forgot that right after the request we send `close()`. We should explicitly fail in that case then, i.e.
```suggestion
    if (this.onResponse.has(sender.streamId)) {
       throw new Error('It is disallowed to use the same stream for multiple requests.');
    }
    this.onResponse.set(sender.streamId, onResponse);
```
