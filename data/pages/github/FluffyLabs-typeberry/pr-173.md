# Comparison benchmark & renames.

## Pull Request by @tomusdrw

Initially I started to optimize `isEqualTo` method using `Uint32Array`, but in benchmarks it turned out to be much slower than I expected. We've been debugging this together with @mateuszsikora and it seems that just creating `DataView` or `Uint32Array` is quite expensive. It's also pretty expensive to read `byteLength` from them (so never do that :)).

The benchmarks are quite on par now, but only because we create the `Uint32Array` outside of the benchmark code.

The PR is then some tiny optimisations to `isEqualTo` (for instance we can shave off 3% of performance by not going to `BytesBlob` prototype) and some renames + the benchmark.
