# PVM: add standard program decoder package

## Pull Request by @mateuszsikora

# What? 
This PR adds a package that allows to decode a program in standard format and provides:
- program code
- initial registers 
- memory segments

Additionally I added a function `checkAndType` (better name is welcome) that performs a code assertion and returns a new type. This type can be used to pass this value somewhere and indicate there that this value doesn't need to be checked again.

unfortunately it is not possible. in case that you don't need a new type you can use `check` function. The aim here is to have a new variable (that have a different type) that you can pass somewhere and you don't have to use ensure/check again.

the change that you suggested (`: a is U {`) won't work because the type guard function needs to return a boolean value and it make sense together with if / switch statement only. for example 
```ts
if (ensure<number, PositiveNumber>(x, x >= 0, 'x is not a positive number')) {
  // here x is PositiveNumber
} 
```

my idea was:
```ts
function foo(length: PositiveNumber) {
  // ensure / check is not needed here
}

function bar(x: number) {
  const length = ensure<number, PositiveNumber>(x, x>=0, 'x is not a positive number');
  foo(length);
}
```

so it is going to be something like the class that you proposed in a different PR:

```ts
class MemIndex {
  constructor(public readonly idx: number) {
     check(idx > 0 && idx < MAX_MEM && isInteger(idx));
  }
}
```

but without being a performance killer
