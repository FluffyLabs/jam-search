# Add missing dependencies between packages.

## Pull Request by @tomusdrw

This PR adds all missing dependencies between packages. Also it fixes recent failure on trie publishing (it was requiring a wrong package).

I've also added a check to enforce that the deps are explicitly defined in `package.json`. Unfortunately it seems it's only available in eslint for now, hence the `+11k` change since we're fetching half of the internet now.

Biome has a lint that SHOULD work for what we want (https://biomejs.dev/linter/rules/no-undeclared-dependencies/) but it's pretty recent and does not support workspaces correctly (see https://github.com/biomejs/biome/issues/2475) and it seems it requires a bigger refactor, so I don't think it will land soon.
