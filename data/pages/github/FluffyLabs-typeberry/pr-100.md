# Add typescript build step

## Pull Request by @tomusdrw

Supersedes #98

To catch more type errors during compile time I've added `tsc` compilation as a build step.

However due to some issues with `@polkadot/api` and `benny` I had to enable `skipLibCheck` to prevent typescript from validating the `d.ts` files in `node_modules`.


## Comment by @mateuszsikora

I would use noEmit option (we use ts-node so we don't need compiled files):
https://www.typescriptlang.org/tsconfig/#noEmit

Also you would extend `ts-node` config from node_modules to avoid discrepancy:
```
{
  "extends": "@tsconfig/node20/tsconfig.json"
}

```

why do you need it ?


## Comment by @tomusdrw

@polkadot/api is an `ECMAScript` module, while `commit-hash/index` is a `CommonJS module`. This triggers a typescript error. I've added a comment to explain that in the code.
