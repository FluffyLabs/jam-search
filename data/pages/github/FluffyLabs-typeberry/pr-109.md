# PVM: fix overflow in address calculatation

## Pull Request by @mateuszsikora

# What? 
This PR fixes problems with wrapping memory addresses:
- in case of indirect address - it is `a + b % 32` instead of `a + b`
- in case of direct addresses - "the last page case" is handled (for example reading 4 bytes from the last memory page when address is `2 ** 32 - 1`). if the desired segment exceeds the last page then the next page is `0` (the first page). 

# Additional changes:
- renamed `add` to `addWithOvefrlow` to indicate that overflow is handled correctly
- added benchmark to check how to wrap page number in the best way 

This PR closes https://github.com/FluffyLabs/typeberry/issues/63
