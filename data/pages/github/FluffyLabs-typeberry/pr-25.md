## Comment by @tomusdrw

IMHO a less error-prone way of doing that kind of pattern is having the caller of the API maintain the `results` and instead of doing `getArgs(pc)` you'd do `fillArgs(pc, results)`.

In such scenario it's much clearer for the caller that `results` have to be re-used, so can't be stored somewhere, etc.

However this is a bit of a nit here, since it's only used in one place, so I don't think it requires the extra hustle.
