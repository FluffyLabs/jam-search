# PVM: store ind instructions

## Pull Request by @mateuszsikora

# What?
This PR introduces support for store instructions that use indirect addressing. The logic here is similar to other store instructions, the difference is only in memory address. One part of an address is immediate number and the second part is stored in a register. Those two numbers have to be summed to get the address.
