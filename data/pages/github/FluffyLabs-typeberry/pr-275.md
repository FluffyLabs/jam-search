## Comment by @tomusdrw

Yes. The `HashSet` is backed by a `HashDictionary`. That's a general issue with JavaScript compared to Rust = no move semantics. For instance does `SortedSet.fromArray` copy the input array or keeps both in sync - not clear just from the function declaration. And in JS alone we have examples that go different ways (i.e. `new Uint8Array([1, 2, 3])` (copy) vs `new Uint8Array(arrayBuffer)` (ref));

Note that the constructor is private and we limit it's usage via more descriptive `static` methods. The reason for `fromDictionary` was to be able to just "view" the keys of a dictionary in a `HashSet`-compatible API. I've renamed the method, let me know if it's cleaner.
