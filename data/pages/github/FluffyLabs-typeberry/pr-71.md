# PVM: basic block validation

## Pull Request by @mateuszsikora

# What?
We didn't validate if the jump/branch destination is the beginning of basic block. The problem was described [here](https://github.com/FluffyLabs/typeberry/issues/68). When I worked on this validation I spotted one more critical problem - dynamic jump instructions returns a destination index not an offset (like in case of branch instructions). It is fixed as well as part of this PR.

As part of this PR I introduces `BasicBlocks` class - I am not sure if it was a good move - maybe it would be better to add this logic to `Mask` class (and rename it to something like `ProgramMetadata`?) ?

This PR closes https://github.com/FluffyLabs/typeberry/issues/68
