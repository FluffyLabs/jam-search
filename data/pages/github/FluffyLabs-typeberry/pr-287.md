# refactor lookup hc to GP 6.3.0

## Pull Request by @r0tc

Draft for lookup hc refactoring.

Points to discuss:
1. I'm not sure what should be done in regards to variable `a`. As far as I understand service index remains 32 bit length, but here https://graypaper.fluffylabs.dev/#/85129da/2fc9012fcd01?v=0.6.3 `2^64 - 1` was introduced. We have `CURRENT_SERVICE_ID` [defined](https://github.com/FluffyLabs/typeberry/blob/main/packages/jam/jam-host-calls/utils.ts#L6) here as basically max 32bits. Could someone help me decide what to do there?
2. Because registers become 64 bit, I added `bigint` to ensure function for memory index https://github.com/FluffyLabs/typeberry/compare/migrate-lookup-hc?expand=1#diff-ff2b61d6ce715ca7d37b9e8a79171211f46733fda5ac363fcfe2381b3c26f28bR7 I think it's safe, but wanted explicitly ask reviewer for check.
