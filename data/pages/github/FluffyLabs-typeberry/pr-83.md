# Initial workers & state machine utilities

## Pull Request by @tomusdrw

This PR introduces the first worker thread (block generator) and a basic structure to handle communication between workers and the main thread.

The proposed idea is to structure the code as a state machine. The state should encapsulate:
1. Possible actions a developer can do in a particular state
2. All signals that the worker can receive from other workers (signals = "notifications")
3. All requests that the worker can respond to from other workers (requests -> response)
4. Possible subscriptions in the future (i.e. I'm interested in some notifications of a particular thing only for some limited amount of time).
