# Reading all codec tests from JSON.

## Pull Request by @tomusdrw

This PR introduces (test-only for now) data structures required to read the `codec` test data.

The tests are not run yet, since that requires reading the corresponding `.bin` files and decode them with our JAM codec, but since it's already quite a lot of code I've decided to make a PR already.

These data structures might (but not necessarily must) match the data model we will have in core. However there is an issue with naming (camelCase vs snake_case), which could be handled by a smarter json parser. Alternatively we will have the data structures duplicated.
