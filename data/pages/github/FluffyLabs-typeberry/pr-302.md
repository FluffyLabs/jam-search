# State merkleization & jamduna test vectors stub.

## Pull Request by @tomusdrw

Closes #269 
Related #237 

This PR implements state merkelization. To make sure we do that correctly I've also decided to load a bunch of jamduna test vectors (from here: https://github.com/jam-duna/jamtestnet/blob/8e3bbeca51af2926c1f2812e10bce020eb3e453f/data/assurances/state_transitions/1_005.json)

- [x] Implement the actual merkelization
- [x] Refactor the test runner to support multiple test suites
- [x] Make the serialization & merkelization test use a proper state object rather then load it from JSON (this has been moved to the test runner).

### How to run jamduna vectors

**Note that we only test state serialization & merkle root, NOT the actual transition!**

Running the test vectors is currently a bit messy because:
1. We don't support 0.6.4 that's in latest master
2. Previous test vectors contain errors (incorrect JSON)

but it's possible to run a bunch of tests from this commit: https://github.com/jam-duna/jamtestnet/blob/8e3bbeca51af2926c1f2812e10bce020eb3e453f

```
$ git clone https://github.com/jam-duna/jamtestnet.git
$ cd jamtestnet && git checkout 8e3bbeca51af2926c1f2812e10bce020eb3e453f
$ cd ../typeberry
$ npm run jamduna -w @typeberry/test-runner -- ../jamtestnet/data/assurances/state_transitions/1_*.json
```
