# PVM: handle page faults

## Pull Request by @mateuszsikora

# What?
I did a few changes:
- expose function that are required by tooling team
- page fault handling - to pass last 3 tests
- simplify instruction tables - name is not needed 

As part of page fault handling I changed a bit `Memory` implementation and it is the most significant change in this PR. Previously `load` and `store` methods checked whether they have appropriate permissions. In the current version they don't verify it anymore. Instead of that `Memory` class exposes 2 additional methods: `isReadable(address: number)` and `isWritable(address: number)` and a client needs to check it manually. 

Also I fucked up the code on main branch (tests don't work). It is fixed on `ms-pvm/dynamic-jumps` so this is why it is the base branch.
