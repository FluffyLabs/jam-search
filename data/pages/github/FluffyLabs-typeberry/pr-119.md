# Refactor logger.

## Pull Request by @tomusdrw

1. Remove `newLogger` function and use `Logger.new` instead.
2. Remove the annoying two-step configuration of the global logger. Now there is `Logger.configureAll` function.
3. To better support browser we use `global.__filename` instead of `__filename` (i.e. undefined vs reference error).
