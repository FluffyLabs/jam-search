# Codec API

## Pull Request by @mateuszsikora

I added a simple http service that allows to encode/decode data using JAM codec. Also I added `Dockerfile` that allows to run the service inside of docker container but the current solution is far away from being optimal. I had to use `ts-node` because `tsc` doesn't copy package.json files to `dist` dir so I am not able to run the app.  When the app is running you should be able to see swagger UI on `/docs`
