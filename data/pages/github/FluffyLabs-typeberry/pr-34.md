# PVM: ThreeRegsDispatcher tests

## Pull Request by @mateuszsikora

# What?
As all 3-register instructions are handled I decided to add a few test to ensure that. Tests check if each 3-register instruction is handled by `ThreeRegsDispatcher` and if other instructions are not handled by this class,  **but they don't check if the correct handler is called.** Tests that check correctness will be added separately.

# Why?
- the correctness is checked e2e by the official tests so there is no pressure to duplicate it
- I had to figure out how mocking works in `node:test` :)
