# Assign host call (+ refactor)

## Pull Request by @tomusdrw

I realised I've been using `as` conversions too lightly. Coming from Rust I kind of forgot that TypeScript allows many unsafe casts via `as` as well. For instance it's totally fine to do `const v: number | null = null; const x = v as number;` and I think it will be quite unsafe but also cumbersome to keep doing the `as` casts.

This PR introduces `assign` host call, but also does a little bit of clean-up with `as` conversions. The rest should follow as described in #166.
I'm not yet sure what's the best way forward here, since probably should be avoiding any code that can throw exceptions in critical code path (mostly due to security/consensus bug issues not performance) but let's see if we figure out something along the way.
