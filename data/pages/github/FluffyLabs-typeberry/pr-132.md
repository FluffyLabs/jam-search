# Erasure coding

## Pull Request by @mateuszsikora

This PR introduces basic functions to encode/decode data using [reed-salomon-wasm package](https://github.com/FluffyLabs/reed-solomon-wasm). Please not that most of the official test vectors are incorrect (they don't meet GP requirements) so this package will be changed in the future. At this moment we are able to encode 342 words (342 * 2 bytes) as 1023 shards and reconstruct the original data from random subset (342 words) of 1023 shards.
