# fix: test run command

## Pull Request by @mateuszsikora

Recently I changed run test command and... it stopped working. This PR should fix it.I compared [glob](https://www.npmjs.com/package/glob), the previous solution the the first solution (`find`) and the performance is similar. `glob` has a lot of dependencies so I decided to say sorry to `find`.

I modified a bit the find command to collect all file paths and then apply it at once (instead of `find -exec`). The difference is that now we have one summary at the end (previously each file had each own summary).
