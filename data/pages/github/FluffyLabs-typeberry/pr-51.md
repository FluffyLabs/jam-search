# PVM: add memory implementation with basic load and store instructions

## Pull Request by @mateuszsikora

This PR introduces memory to PVM. It is not fully functional yet. There are still 5 load and 6 store instructions that need to be added but I decided to do it in a separate PR.

Changes:
- memory implementation
- page map implementation 
- new tests are written using `describe` and `it` - no `async`-`await`
- basic support for load operations:
  - load_u8
  - load_u16
  - load_u32
- basic support for store operations:
  - store_u8
  - store_u16
  - store_u32
  - store_imm_u8
  - store_imm_u16
  - store_imm_u32

I decided to split memory implementation into at least 3 PRs. Next steps:
- add support for load_i instructions (it needs some special encoding so it is better to do it separately)
- add support for the rest of store/load instructions
