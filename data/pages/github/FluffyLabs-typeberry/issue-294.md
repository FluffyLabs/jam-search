# Machine HostCall documentation update

## Issue by @DrEverr

I suggest updating comments and function names to better reflect what this HostCall contains and utilizes. The current function naming is misleading—'Machine HC' is not about **starting** a machine but about **instantiating** it, so all related functions should be named accordingly. On the other hand, 'Invoke HC' is responsible for starting a machine.
