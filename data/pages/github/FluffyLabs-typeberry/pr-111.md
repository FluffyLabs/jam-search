# Initial version of JAM codec

## Pull Request by @tomusdrw

The PR introduces a complete initial version of the JAM Codec. We had some stub initially (i.e. the natural number encoding), but now it's changed a bit to create a common API.

## What's here?

1. `Encoder` and `Decoder` classes that should be roughly API-symmetric.
2. Encoding of primitive types defined in the graypaper:
    - [x] 1,2,3,4-byte fixed-size numbers (we may consider bigint/u64 in the future)
    - [x] variable-size 4-byte numbers(u32) and 8-byte numbers (bigint/u64)
    - [x] sequences (fixed & variable size)
    - [x] optional values (set union)
    - [x] Special casing for byte-sequences `Bytes<N>` and `BytesBlob`
    - [x] Special casing for bit sequences `BitVec` (+ `BitVec` implementation)
    
3. Auxiliary code
   - [x] BigInt decoding benchmarks (bigint vs u32 *2)
   - [x] BitInt comparison benchmarks (bigint vs u32 *2)
   - [x] BitVec implementation using `Uint8Array` (a packed sequence of bits)
   - [x] Hide constructors of `Bytes` and `BytesBlob` and use constructor methods instead.


Since the PR is already massive, I'm planning to get that reviewed & merged first and then I want to work with applying the decoder/encoder for more complicated structures (like the entire `Block`).
