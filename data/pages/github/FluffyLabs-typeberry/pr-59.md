## Pull Request by @mateuszsikora

# What?
This PR unifies approach to instructions. No args instructions (`trap` and `fallthrough`) got they own dispatcher and ops classes and some simple tests. Also this PR is the first step to handle non-happy paths in PVM - status is moved to `InstructionResult` and can stop the program execution. As next steps I am going to review GP to find places that can stop program execution and I will add a proper conditions.
