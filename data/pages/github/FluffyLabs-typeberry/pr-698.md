# Add `require curly braces` rule to linter

## Pull Request by @DrEverr

this rule requires to change code like this
```typescript
if (foo) foo++;

while (bar)
    baz();

if (foo) {
    baz();
} else qux();
```

to this
```typescript
if (foo) {
    foo++;
}

while (bar) {
    baz();
}

if (foo) {
    baz();
} else {
    qux();
}
```
