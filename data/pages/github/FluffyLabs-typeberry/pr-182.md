## Comment by @tomusdrw

So all of the host calls are marked as async, but none of the `partialState` functions are yet. That's intentional - if possible the `partialState` stuff should be all sync, but I don't want to block a possibility in the future (i.e. it will be a bit more painful to rewrite all host calls as async then to "optimize" this at some point to be fully sync).
