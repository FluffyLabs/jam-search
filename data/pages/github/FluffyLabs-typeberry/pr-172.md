# Codec: Skipping values

## Pull Request by @tomusdrw

After #170 (and an addition of `Skipper` in this PR) it turns out we can fairly nicely optimize creating views.

Instead of decoding all fields prior to the field we want we skip their byte representation. For objects that have fixed-byte size the operation is straight forward. For some other objects we might need to read some data before we are able to move forward.
The biggest gain should come from being able to skip entire nested objects with exact `sizeHint`.
