# Import WASM module to verify Bandersnatch signatures.

## Pull Request by @tomusdrw

The PR imports a WASM version of https://github.com/FluffyLabs/bandersnatch (see branch `pkg`) and uses it in the safrole test code.

The function does not yet verify signatures (actually it fails, because the code is trying to generate the ring vrf context which requires randomness, which in turn is not available in WASM) however I wanted to include the code as-is now, to show how this can be done.
Further work of actually verifying signatures should follow both on the `bandersnatch-wasm` lib and the Safrole code.


On top of that I've made the tests run asynchronously and in parallel (related #19)
