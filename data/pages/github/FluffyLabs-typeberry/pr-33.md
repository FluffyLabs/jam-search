# Add .editorconfig

## Pull Request by @tomusdrw

This PR adds `.editorconfig` file. I've noticed that `biome` is indenting using tabs for some reason.

Editorconfig support for `biome` has been recently merged (like 3 weeks ago) https://github.com/biomejs/biome/pull/3343 so I think the next version should start to adhere to the `.editorconfig`.

For now I've manually configured biome to use spaces and match the `.editorconfig`.

Note it required a full codebase re-format 🙈
