# Make `map_vs_sorted` benchmark a bit more realistic.

## Pull Request by @tomusdrw

Previous benchmark was comparing many different things, hence such a drastic difference between `Map` and the rest. Initial use case was to actually compare "how fast can we lookup an element" instead of actually comparing these different data structures given similar API requirements.

I've tried to make the examples as similar as possible now. Obviously `Map` is still much faster, since we are getting the key in one go instead of iterating.
