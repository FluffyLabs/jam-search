# Prepare for mocked demo.

## Pull Request by @tomusdrw

This PR adds a bunch of quickly stitched together components which will allow us to prepare a end-to-end demo for the retreat to work on.

Namely there is:
1. `SortedArray` data structure (will probably stay)
2. `HashDictionary` data structure (will probably stay, but must be optimized)
3. Initial database for blocks & trie (in memory; might stay for tests)
4. Importer worker (will be reworked)
5. Block generator (will go away)

All of that stuff is a bit asorted, because I'm trying to get as much done before the weekend, but still it would be good to review everything.

  public findIndex(v: V) {
    const findIdx = this.binarySearch(v);

      return false;
