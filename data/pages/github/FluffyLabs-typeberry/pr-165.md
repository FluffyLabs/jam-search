# Empower host call + test

## Pull Request by @tomusdrw

I've added a dictionary encoder/decoder, but ended up not using it in the empower test cases because:
1. We can avoid reading big chunk of memory at once in main code.
2. In tests it's easier to manipulate a `[key, value][]` than a dictionary to create invalid entries.

However I think the encoding will be useful in future anyway, so leaving it here.
