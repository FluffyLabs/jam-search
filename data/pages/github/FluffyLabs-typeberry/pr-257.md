# Assurances test vectors

## Pull Request by @tomusdrw

Resolves #239 

Some extra stuff:
- [x] Moved `AvailabilityAssignment` from disputes to a shared package.
- [x] Added `sumWith` (I thought I need it initially, but I didn't - pretty sure it would be useful though) and `indicesOfSetBits` to `BitVec`. 
- [x] Added `deepEqual` test utility. I got already tired with `assert.deepStrictEqual` returning hard-to debug data. Initially started writing a util only for `assurances`, but turned out it can easily be made generic, hence moved to `@typeberry/utils`.
- [x] Added `PerCore` and `PerValidator` collections that used to be `KnownSizeArrays`, but actually could be `FixedSizeArrays`, although they depend on chainspec. I think we should be using the same `tryAs*` pattern for these and avoid blindly doing `asOpaqueType` for such collections. Used these in `disputes` as well 
- [x] ed25519 signature verification moved to `@typeberry/crypto` shared package and the API is unified and could be easily replaced with some other implementation (ASM/Rust) if needed.
