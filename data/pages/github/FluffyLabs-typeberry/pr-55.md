# PVM: LOAD_I8 i LOAD_I16 instructions

## Pull Request by @mateuszsikora

# What?
This PR introduces support for two instructions: LOAD_I8 and LOAD_I16. They read 1 or 2 bytes from memory as a signed number and if this number is negative (MSB is equal to `1`) then missing bytes in destination register are filled using `0xff` to preserve the same value but make the number "longer".
