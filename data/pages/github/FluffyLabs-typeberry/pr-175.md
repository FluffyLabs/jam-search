# Getting encoded data from the view.

## Pull Request by @tomusdrw

Since `View` is just a perspective over raw data, it should be easy to get the original encoded value.
In the constructor we are getting the `initial` position within the source vector, and then after skipping all fields we can figure out where the end index is.

This PR adds `encoded()` method to the view that just returns a subarray of the source where our object is encoded.


It might be useful to be able to get encoded values of individual fields (which are not `Views` themselves), but that would require adding more methods so I've kept it for later for now.
