# PVM: better way of looking for a next instruction in program

## Pull Request by @mateuszsikora

# What?
I improved a bit the algorithm that we use to:
- check if a byte is an instruction or an argument (check if nth bit is 1 or 0)
- get number of bytes to the next instruction (look for a next 1 in bit mask)

In the previous implementation we work on raw byte array and calculate needed information on demand. In the new implementation I build a lookup table that keeps distances to next 1, so I need to go through the bytes only once to build the table and then I can quickly answer for each index if it is an instruction or how many bytes we have to skip to get the next instruction.

it resolves the first item from:  https://github.com/FluffyLabs/typeberry/issues/13
