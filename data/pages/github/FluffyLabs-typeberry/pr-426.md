# Build binary w/ publish packages

## Pull Request by @DrEverr

Resolves: #373 

Publishing to:
 - **npm**, 
 - **GitHub Packages**, 
 - **GitHub Pages**

Features:
 - Rollup build
 - Binary generation with version and git hash
 - WASM files automatically copied
 - CommonJS format with `.cjs` extension
 - Native dependencies (lmdb) externalized

Automation: 
 - **publish.yml`**: Automated publishing on git tags
 - **pages.yml`**: GitHub Pages deployment
 - **Triggers**: Git tags (`v*`), releases, manual dispatch
 - **scripts/create-symlink.cjs`**: Handles versioned filename → consistent name

Published package will include:
- `typeberry.cjs` - Main executable
- `*.wasm` files - WebAssembly dependencies  
- README and LICENSE
