## Comment by @tomusdrw

IMHO it would be cleaner if this was just a `static` builder method for `BasicBlocks`.  During runtime it does not need `code` or `mask` for anything, it's just there to construct the object that later is just a `Set<number>`.

Alternatively just don't assign the fields in `reset` and just compute the basic blocks from there. Now it's a bit confusing to have multiple fields in a potentially inconsistent state before `calculateBasicBlocks` is called.
