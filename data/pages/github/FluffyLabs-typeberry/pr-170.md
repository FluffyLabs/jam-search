# Small codec improvements

## Pull Request by @tomusdrw

This PR is adding two new features to codec:
1. The `sizeHintBytes` is changed into a more complex object, where we track not only the bytes, but also if the bytes are actually the exact size of the encoded type. This allows us to auto-calculate the byte-size of encoded version of some complex data types iff all their fields have exact size hints.
2. A more-relaxed version of `Class` descriptor, where we don't care about the prototype chain at all, just the shape of the object. This allows for more ad-hoc object creation.

## Comment by @tomusdrw

So the logic is as follows:
1. if `a.bytes` OR `b.bytes` is set make sure that the sum will contain that value AND the other value added (or 0 if the other value is not present).
2. We are `isExact` iff both values are exact.

Examples (for bytes only, because `isExact` is simple enough):
```ts
a.bytes = 4;
b.bytes = undefined;
sum(a, b) = 4

a.bytes = undefined;
b.bytes = 4;
sum(a, b) = 4;

a.bytes = 4;
b.bytes = 4;
sum(a, b) = 8;

a.bytes = undefined;
b.bytes = undefined;
sum(a, b) = undefined;
```
