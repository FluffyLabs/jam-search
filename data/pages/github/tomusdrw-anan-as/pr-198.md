# Support resuming the compiler entry point from host calls

## Pull Request by @tomusdrw

This PR adds a bunch of external functions to index-compiler.ts to make it possible to resume it from host calls. Note this follows a much simplified API compared to the WASM version to make it easier to handle externally.

The idea is to use this for PVM-in-PVM tests, notably be able to forward ecalli from inner programs all the way up to the outer interpreter. 🤞
