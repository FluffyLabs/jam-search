<p>This rule disallows the use of <code>javascript:</code> URLs, which are considered a form of <code>eval</code> and can pose security risks such as XSS vulnerabilities.</p>

<h4>Invalid</h4>
<pre lang="js"><code>await &quot;value&quot;;
<p>const createValue = () =&gt; &quot;value&quot;;<br />
await createValue();<br />
</code></pre></p>
<h4>Caution</h4>
<p>This is a first iteration of the rule, and does not yet detect generic <a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise#thenables">&quot;thenable&quot;</a> values.</p>
</li>
