<blockquote>
<h2>Biome CLI v2.3.15</h2>
<h2>2.3.15</h2>
<h3>Patch Changes</h3>
<ul>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/9019">#9019</a> <a href="https://github.com/biomejs/biome/commit/043b67c608f99a27c775deefb9f00b43839251ae"><code>043b67c</code></a> Thanks <a href="https://github.com/dyc3"><code>@​dyc3</code></a>! - Added the lint rule <a href="https://biomejs.dev/linter/rules/no-nested-promises/"><code>noNestedPromises</code></a>. This rule detects nested <code>.then()</code> or <code>.catch()</code> calls that could be refactored into flat promise chains.</p>
<pre lang="js"><code>// Invalid: nested promise that can be flattened
doThing().then(function () {
  return doOtherThing().then(console.log);
});
<p>// Valid: flat promise chain<br />
doThing()<br />
.then(() =&gt; doOtherThing())<br />
.then(console.log);<br />
</code></pre></p>
<p>The rule intelligently allows nesting when the inner callback references variables from the outer scope, as these cases cannot be safely flattened.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/9029">#9029</a> <a href="https://github.com/biomejs/biome/commit/6ebf6c605f20a504aa5f23477f2e9be32437fb90"><code>6ebf6c6</code></a> Thanks <a href="https://github.com/ff1451"><code>@​ff1451</code></a>! - Added the nursery rule <a href="https://biomejs.dev/linter/rules/no-useless-return/"><code>noUselessReturn</code></a>. The rule reports redundant <code>return;</code> statements that don't affect the function's control flow.</p>
<pre lang="js"><code>// Invalid: return at end of function is redundant
function foo() {
  doSomething();
  return;
}
</code></pre>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/9017">#9017</a> <a href="https://github.com/biomejs/biome/commit/8bac2da137bb1b697be1ebf41a11088c0220ce65"><code>8bac2da</code></a> Thanks <a href="https://github.com/mdevils"><code>@​mdevils</code></a>! - Reverted a behavior change in <a href="https://biomejs.dev/linter/rules/use-exhaustive-dependencies/"><code>useExhaustiveDependencies</code></a> that was accidentally included as part of the <a href="https://redirect.github.com/biomejs/biome/issues/8802">#8802</a> fix. The change made method calls on objects (e.g., <code>props.data.forEach(...)</code>) report only the object (<code>props.data</code>) as a missing dependency instead of the full member expression. This behavior change will be reconsidered separately.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/9005">#9005</a> <a href="https://github.com/biomejs/biome/commit/c8dbbbe9363fb156a29de174ba7735154f6bc783"><code>c8dbbbe</code></a> Thanks <a href="https://github.com/corvid-agent"><code>@​corvid-agent</code></a>! - Fixed <a href="https://redirect.github.com/biomejs/biome/issues/8790">#8790</a>: The <a href="https://biomejs.dev/linter/rules/no-assign-in-expressions/"><code>noAssignInExpressions</code></a> rule no longer reports a false positive when an assignment is used as the expression body of an arrow function (e.g., <code>const f = b =&gt; a += b</code>).</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/8519">#8519</a> <a href="https://github.com/biomejs/biome/commit/ccdc602d8ab8e7b14b7cbae2b12cdf396edb8301"><code>ccdc602</code></a> Thanks <a href="https://github.com/ruidosujeira"><code>@​ruidosujeira</code></a>! - Fixed <a href="https://redirect.github.com/biomejs/biome/issues/8518">#8518</a>, where globally excluded files in a monorepo were still being processed when using <code>&quot;extends&quot;: &quot;//&quot;</code>.</p>
<p>When a package-level configuration extends the root configuration with <code>&quot;extends&quot;: &quot;//&quot;</code>, glob patterns (such as those in <code>files.includes</code>) are now correctly resolved relative to the project root directory, instead of the current workspace directory.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/9033">#9033</a> <a href="https://github.com/biomejs/biome/commit/0628e0a238d9c9c750e4f44c460455183a0ff70e"><code>0628e0a</code></a> Thanks <a href="https://github.com/mdevils"><code>@​mdevils</code></a>! - Fixed <a href="https://redirect.github.com/biomejs/biome/issues/8967">#8967</a>. <a href="https://biomejs.dev/linter/rules/use-exhaustive-dependencies/">useExhaustiveDependencies</a> no longer reports false positives for variables destructured from a rest pattern.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/9023">#9023</a> <a href="https://github.com/biomejs/biome/commit/8ef9d1d81c416a9f4d42527f4c263bc3f2e423b1"><code>8ef9d1d</code></a> Thanks <a href="https://github.com/siketyan"><code>@​siketyan</code></a>! - Fixed <a href="https://redirect.github.com/biomejs/biome/issues/9020">#9020</a>: When <code>javascript.jsxRuntime</code> is set to <code>reactClassic</code>, <code>noUnusedImports</code> and <code>useImportType</code> rules now allow importing the <code>React</code> identifier from a package other than <code>react</code>. This aligns the behavior with <code>tsc</code> (<code>--jsx=react</code>), which also allows importing <code>React</code> from any package.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/8646">#8646</a> <a href="https://github.com/biomejs/biome/commit/16fd71da5692f863112e302078325d3be4d79b24"><code>16fd71d</code></a> Thanks <a href="https://github.com/siketyan"><code>@​siketyan</code></a>! - Fixed <a href="https://redirect.github.com/biomejs/biome/issues/8605">#8605</a>: Text expressions in some template languages (<code>{{ expr }}</code> or <code>{ expr }</code>) at the top level of an HTML document no longer causes panicking.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/8930">#8930</a> <a href="https://github.com/biomejs/biome/commit/51c158e803f9bad561cf5b79365c339e9069d614"><code>51c158e</code></a> Thanks <a href="https://github.com/ANKANJAGTAP"><code>@​ANKANJAGTAP</code></a>! - Fixed <a href="https://github.com/biomejs/biome/tree/HEAD/packages/@biomejs/biome/issues/8917">#8917</a>
<a href="https://biomejs.dev/linter/rules/use-exhaustive-dependencies/">useExhaustiveDependencies</a> now correctly detects JSX component identifiers as hook dependencies.</p>
</li>

<p><a href="https://redirect.github.com/biomejs/biome/pull/9009">#9009</a> <a href="https://github.com/biomejs/biome/commit/7d229c7ca3930ff56e3a229a70b994f1d5fd1086"><code>7d229c7</code></a> Thanks <a href="https://github.com/Netail"><code>@​Netail</code></a>! - Fixed typo in <a href="https://biomejs.dev/linter/rules/no-positive-tabindex/">noPositiveTabindex</a>'s quick fix text.</p>
