</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/7358">#7358</a> <a href="https://github.com/biomejs/biome/commit/963a24643cbf4d91cca81569b33a8b7e21b4dd0b"><code>963a246</code></a> Thanks <a href="https://github.com/ematipico"><code>@​ematipico</code></a>! - Fixed <a href="https://redirect.github.com/biomejs/biome/issues/7085">#7085</a>, now the rule <code>noDescendingSpecificity</code> correctly calculates the specificity of selectors when they are included inside a media query.</p>
