<summary>Release notes</summary>

<blockquote>
<h2>Biome CLI v2.2.0</h2>
<h2>2.2.0</h2>
<h3>Minor Changes</h3>
<ul>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/5506">#5506</a> <a href="https://github.com/biomejs/biome/commit/1f8755bfcbcd913be9fc1961b45b5c7ade8695c3"><code>1f8755b</code></a> Thanks <a href="https://github.com/sakai-ast"><code>@​sakai-ast</code></a>! - The <code>noRestrictedImports</code> rule has been enhanced with a new <code>patterns</code> option. This option allows for more flexible and powerful import restrictions using gitignore-style patterns.</p>
<p>You can now define patterns to restrict entire groups of modules. For example, you can disallow imports from any path under <code>import-foo/</code> except for <code>import-foo/baz</code>.</p>
<pre lang="json"><code>{
  &quot;options&quot;: {
    &quot;patterns&quot;: [
      {
        &quot;group&quot;: [&quot;import-foo/*&quot;, &quot;!import-foo/baz&quot;],
        &quot;message&quot;: &quot;import-foo is deprecated, except for modules in import-foo/baz.&quot;
      }
    ]
  }
}
</code></pre>
<p><strong>Invalid examples</strong></p>
<pre lang="js"><code>import foo from &quot;import-foo/foo&quot;;
import bar from &quot;import-foo/bar&quot;;
</code></pre>
<p><strong>Valid examples</strong></p>
<pre lang="js"><code>import baz from &quot;import-foo/baz&quot;;
</code></pre>
<p>Additionally, the <code>patterns</code> option introduces <code>importNamePattern</code> to restrict specific import names using regular expressions.
The following example restricts the import names that match <code>x</code> , <code>y</code> or <code>z</code> letters from modules under <code>import-foo/</code>.</p>
<pre lang="json"><code>{
  &quot;options&quot;: {
    &quot;patterns&quot;: [
      {
        &quot;group&quot;: [&quot;import-foo/*&quot;],
        &quot;importNamePattern&quot;: &quot;[xyz]&quot;
      }
    ]
  }
}
</code></pre>
</li>
</ul>
