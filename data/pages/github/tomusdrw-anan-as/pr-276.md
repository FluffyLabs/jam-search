</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/10094">#10094</a> <a href="https://github.com/biomejs/biome/commit/e00714360807115210e549caca0f235431ca9a8a"><code>e007143</code></a> Thanks <a href="https://github.com/THEjacob1000"><code>@​THEjacob1000</code></a>! - Added the nursery rule <a href="https://biomejs.dev/linter/rules/no-tailwind-arbitrary-value/"><code>noTailwindArbitraryValue</code></a>. </li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/8239">#8239</a> <a href="https://github.com/biomejs/biome/commit/a519f9d19e56015ec906efac4629fbb15708f5e2"><code>a519f9d</code></a> Thanks <a href="https://github.com/cormacrelf"><code>@​cormacrelf</code></a>! - Fixed <a href="https://redirect.github.com/biomejs/biome/issues/8233">#8233</a>, where Biome CLI in
stdin mode didn't work correctly when handling files in projects with nested
configurations. For example, with the following structure,
<code>--stdin-file-path=subdirectory/...</code> would not use the nested configuration in
<code>subdirectory/biome.json</code>:</p>
<pre><code>├── biome.json
└── subdirectory
    ├── biome.json
    └── lib.js
</code></pre>
<pre lang="shell"><code>biome format --write --stdin-file-path=subdirectory/lib.js &lt; subdirectory/lib.js
</code></pre>
<p>Now, the nested configuration is correctly picked up and applied.</p>
<p>In addition, Biome now shows a warning if <code>--stdin-file-path</code> is provided but
that path is ignored and therefore not formatted or fixed.</p>
</li>

<p>schedule(async () =&gt; {}) ?? &quot;fallback&quot;;
</code></pre></p>
