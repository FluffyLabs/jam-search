<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/10595">#10595</a> <a href="https://github.com/biomejs/biome/commit/f4580289094a8fe5c85252adc3399c060bab811e"><code>f458028</code></a> Thanks <a href="https://github.com/pkallos"><code>@​pkallos</code></a>! - Added the option <code>ignoreBooleanCoercion</code> to <a href="https://biomejs.dev/linter/rules/use-nullish-coalescing/">useNullishCoalescing</a>. When enabled, Biome ignores <code>||</code> and <code>||=</code> used inside a <code>Boolean()</code> call, where coalescing on falsy values is intentional.</p>
</li>
<li>
<p><a href="https://redirect.github.com/biomejs/biome/pull/10798">#10798</a> <a href="https://github.com/biomejs/biome/commit/4a32b63eb41f144dc8faf6b5cdb05e1de5dbcb63"><code>4a32b63</code></a> Thanks <a href="https://github.com/pkallos"><code>@​pkallos</code></a>! - Added the option <code>ignorePrimitives</code> to <a href="https://biomejs.dev/linter/rules/use-nullish-coalescing/">useNullishCoalescing</a>. When enabled, Biome ignores <code>||</code>, <code>||=</code>, and ternary expressions whose non-nullish operands are all primitives the option opts out of. Use <code>true</code> to ignore all primitives, or an object selecting <code>string</code>, <code>number</code>, <code>boolean</code>, or <code>bigint</code>.</p>
