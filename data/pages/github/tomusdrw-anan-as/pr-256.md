<pre lang="html"><code>&lt;!-- Invalid: no keyboard handler --&gt;
&lt;div onclick=&quot;handleClick()&quot;&gt;Click me&lt;/div&gt;
<p>&lt;!-- Valid: has keyboard handler --&gt;<br />
&lt;div onclick=&quot;handleClick()&quot; onkeydown=&quot;handleKeyDown()&quot;&gt;Click me&lt;/div&gt;</p>
<p>&lt;!-- Valid: inherently keyboard-accessible --&gt;<br />
&lt;button onclick=&quot;handleClick()&quot;&gt;Submit&lt;/button&gt;<br />
</code></pre></p>
</li>

The rule detects CSS class names used in <code>class=&quot;...&quot;</code> (or <code>className</code>) attributes that are not defined in any <code>&lt;style&gt;</code> block or linked stylesheet reachable from the file.</p>

</code></pre>
