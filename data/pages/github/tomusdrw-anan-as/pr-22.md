# Execute with stdin/stdout

## Pull Request by @tomusdrw

Can be used together with https://github.com/FluffyLabs/pvm-test-harness to execute json test cases alongside PVM.

```
$ RUST_LOG=debug \
  cargo run -- \
  json ../jamtestvectors/pvm/programs/inst_add.json polkavm stdin=../anan-as/bin/stdin.sh
```
