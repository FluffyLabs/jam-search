# [0.8.0] fuzz-proto: minifuzz examples

## Pull Request by @davxy

Adds minifuzz example traces for GP 0.8.0 (`fuzz-proto/examples/0.8.0`) 

Run against a target:

  ```bash
  python minifuzz/minifuzz.py -d examples/0.8.0/forks --target-sock /tmp/jam_target.sock
  python minifuzz/minifuzz.py -d examples/0.8.0/no_forks --target-sock /tmp/jam_target.sock
  ```

Be aware of the deviations listed here: https://github.com/davxy/jam-conformance/pull/212
