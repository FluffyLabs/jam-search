# Support macos architecture

## Pull Request by @alxmirap

This adds support for macos, beyond the default linux.
It reviews all the known teams for the right place to download the mac image and the command to execute it.
It also improves the "all" handling, to continue even if some download fails.

I have tested all teams for the expected `get` and `run` behaviour. Most worked, with these exceptions:
- I have been unable to download the docker-based `boka`.
- `jamixir` and `vinwolf` do not support Mac. I could verify the `get` behaviour, but not the `run`.
- I was not able to test `jamzilla` due to difficulties with a missing library. To be investigated further.
