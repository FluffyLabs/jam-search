# Minifuzz

## Pull Request by @davxy

Since I often need to run implementations that are not yet compliant with the fuzzer protocol, I wrote a simple Python script to leave the initial checking to you.

The script checks protocol compliance by replaying a pre-constructed fuzzer session (for example, the one in the `examples` folder).

Requires [jam-types](https://github.com/davxy/jam-types-py).

After starting your target, run like:
```sh
❯ ./minifuzz.py --help
usage: minifuzz.py [-h] -d TRACE_DIR [-s {tiny,full}] [-v] [--target-sock TARGET_SOCK]

Minifuzz - Send fuzzer messages to target socket

options:
  -h, --help            show this help message and exit
  -d, --trace-dir TRACE_DIR
                        Directory containing pre-constructed message files
  -s, --spec {tiny,full}
                        Specification to use (default: tiny)
  -v, --verbose         Verbose output (default: false)
  --target-sock TARGET_SOCK
                        Target socket path (default: /tmp/jam_target.sock)
```

Example (to run pre
```
❯ ./minifuzz.py --trace-dir ../examples/v1 --target-sock /tmp/jam_target.sock 
```

Is a bit hacky, but apparently works :-)
