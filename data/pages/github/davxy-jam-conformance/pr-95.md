# Perf round

## Pull Request by @davxy

I decided to set up a better environment for performance testing.  

CPU frequency scaling and boost were disabled to ensure more deterministic results.
This prevents thermal and power-related frequency fluctuations that could skew results.
Locking the CPU to its nominal frequency makes benchmark comparisons more fair and reproducible.

For more details about kernel and environment settings see the perf section in the [README](https://github.com/davxy/jam-conformance/tree/main/fuzz-reports#testing-environment).
