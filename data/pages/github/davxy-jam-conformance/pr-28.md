# Support macos besides linux

## Pull Request by @alxmirap

This adds support for macos,  beyond the default linux.
It reviews all the known teams for the right place to download the mac image.
It also creates a single script `target.sh` to unify the call to `get` and `run`, and extracts common behaviour into a share file `common.sh`.
It also improves the "all" handling, to continue even if some download fails.

I have tested all teams, but I have been unable to download the docker based ones (`boka` and `turbojam`).
Some teams do not support mac, namely: `jamixir`, `vinwolf`. 
Finally, I was not able to test `jamzilla` due to difficulties with a missing library. To be investigated further.
