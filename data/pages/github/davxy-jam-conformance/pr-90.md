# [Fuzz Proto] PVM tracing feature

## Pull Request by @sourabhniyogi

If PVM Tracing is supported by the target (via `feature-pvm-tracing`), the fuzzer may attempt to resolve disputes with a `GetExecutionTrace` message for which the target must respond with a `ExecutionTrace`, containing 176-byte `InstructionTrace`.

This fuzzer protocol feature hopes to replace the manual process of "does anyone have a trace for XXXX" with a standard format amenable to dispute reporting.   At present, PVM execution traces currently have no standard format and require tedious script writing and reasoning concerning sizable text logs between implementations. 

This feature may be used for fuzzing of accumulate, refine and authorize invocations and has filtering to support the rapid detection of differences in very large gas execution (3.5-5B).

Basic memory support (up to 32 bytes) has been added from #65 along with better named field names, from @sierkov
