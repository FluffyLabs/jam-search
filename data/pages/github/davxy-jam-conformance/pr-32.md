# Add GrayMatter client by JamBrains

## Pull Request by @ggwpez

I tested it with the JamZig fuzzer as source. Hope it will work with the PolkaJam fuzzer as well :)

CLI help menu for this command:
```pre
 fuzz-m1-target: Fuzz target for the M1 fuzzer.
   
   Implements the protocol defined by Davide Galassi https://github.com/davxy/jam-stuff/blob/main/fuzz-proto/README.md
   The named listener socket can be set with `--listen` and defaults to `/tmp/jam_target.sock`.
   

   --listen (string) - Path of the named listener socket [default: "/tmp/jam_target.sock"]
   --spec (string) - Chain constants preset (tiny | full) [default: "tiny"]
```

The docker image will only work on Linux x86_64.

PS: We know that we don't yet pass all 0.6.7 vectors, but wanted to submit this anyway to ensure that all the surrounding stuff with the docker image works.
