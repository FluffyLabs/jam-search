# Charge gas to the host-calls

## Pull Request by @davxy

Align gas charging for host functions with the GP :

* In general, host function calls incur in a charge of 10 gas units per invocation.
* An exception is the `transfer` function, which is charged at **10 + \$\omega\_9\$** where \$\omega\_9\$ corresponds to the gas limit parameter
