## Pull Request by @davxy

Traces exercising the fuzzy service:  

- **fuzzy_light**: 1 trace per report, using an empty fuzzy profile (i.e., the profile performs no operations)  
- **fuzzy**: up to 6 traces per report, using a random fuzzy profile

# ⚠️ Deviation ⚠️

A change from version **0.7.2** accidentally made its way into our current codebase.  
In **0.7.2**, service stats need to be updated when the service belongs to an $R^*$ or when any accumulation logic has been executed (i.e. gas consumed, e.g. an incoming transfer).  

https://graypaper.fluffylabs.dev/#/ab2cdbd/18e60318e603?v=0.7.2
