# Edge-case block import traces

## Pull Request by @daiagi

Seven short block import traces, each testing one GP 0.8.0 rule. They sit next to the existing suites under `traces/`, and the traces README has a new section listing them.

- Ready queue and pending availability (11.41). A new report's package must not already be waiting in the ready queue or pending availability. Only the queued and pending packages count, their prerequisites don't.
- Lookup anchor (11.38). The lookup anchor has to be an ancestor with the context's slot and hash, and the block after it has to carry the context's lookup anchor state root.
